## 项目简介
本项目是一个完整的C语言图书管理系统，实现了从用户注册登录、图书增删改查、借阅归还到数据持久化的全流程。核心特点是**高性能数据结构设计**（图书哈希表查找O(1)）、**智能跨天重置**（每日借阅数自动清零）、**双方案前端可视化**（支持Live Server）。

## 目录结构
```
MyFirstProject/
├─ main.c          # 主程序入口（含精美控制台UI）
├─ user.c/h        # 用户管理模块（双向链表存储）
├─ ops.c/h         # 图书操作模块（哈希表存储）
├─ logic.c/h       # 业务逻辑模块（借阅/归还/权限校验）
├─ store.c/h       # 数据持久化模块（CSV导入导出）
├─ data.h          # 数据结构定义（哈希表/链表节点）
├─ config.h        # 配置文件（空文件，可扩展）
├─ index.html      # 前端可视化界面
└─ data/           # 数据存储目录（自动生成）
   ├─ books.csv    # 图书数据
   └─ users.csv    # 用户数据
```

## 功能特性
### 1. 用户管理
- 注册/登录：支持管理员（role=1）和普通用户（role=2）两种角色
- 权限控制：普通用户仅可借阅/归还，管理员可增删改图书
- 每日借阅上限：普通用户每日最多借阅5本
- 跨天自动重置：每日0点后首次操作自动清零所有用户的每日借阅数

### 2. 图书管理
- 管理员功能：添加图书、删除图书、修改库存
- 普通用户功能：借阅图书、归还图书、查看今日借阅情况
- 数据校验：库存不能小于已借出数量，借阅数量不能超过库存/每日上限

### 3. 数据持久化
- CSV格式导入导出：图书数据格式 `ISBN,书名,作者,库存,已借数量`
- 自动保存：程序退出时自动保存所有数据到 `data/` 目录
- 容错处理：导入时跳过格式错误/数据非法的行

### 4. 前端可视化
- 精美Web界面：渐变背景、彩色状态、响应式表格
- 双方案读取：
  - 方案1：VS Code Live Server启动，自动读取 `data/books.csv`
  - 方案2：修改浏览器设置后，双击HTML直接读取（无需服务器）
  - 备选方案：HTML内置文件上传功能，手动选择CSV文件

## 核心优化与创新
### 1. 高性能数据结构设计
- **图书存储：哈希表（Hash Table）**
  - 桶数量设为质数 `101`，减少哈希冲突
  - 采用djb2哈希算法，哈希值分布均匀
  - 查找效率从链表的O(n)优化到O(1)，适合大量图书场景
- **用户存储：双向链表（Doubly Linked List）**
  - 支持快速插入/删除，适合用户注册/注销
  - 尾插法添加新用户，保持注册顺序

### 2. 智能跨天重置机制
- 全局变量 `lastResetDate` 记录上次重置日期（格式：YYYYMMDD）
- 每次借阅前自动调用 `checkAndResetDailyBorrowed()` 检测日期
- 若跨天则自动调用 `resetDailyBorrowed()` 清零所有用户的每日借阅数
- 无需手动操作，完全自动化

### 3. 内存管理与错误处理
- 完整的资源释放函数：`destroyHashTable()` 和 `destroyUserList()`
- 哈希表销毁时遍历所有桶，释放每个节点的字符串内存和节点本身
- 统一错误码定义（`SUCCESS`/`ISBN_EXIST`/`USER_EXIST`等），友好的错误提示
- 输入参数校验：避免空指针/负数/格式错误导致的段错误

### 4. 前端可视化创新
- 无需后端服务器，纯HTML+CSS+JavaScript实现
- 双方案兼容：既支持Live Server的HTTP协议自动读取，也支持本地文件协议的手动选择
- 精美UI设计：渐变背景、彩色状态标签、悬停效果、响应式布局
- 详细错误提示：读取失败时显示具体原因（路径错误/文件不存在/跨域限制等）

## 快速开始
### 环境要求
- 操作系统：Windows（推荐）/ Linux / macOS
- 编译器：GCC（MinGW-w64 for Windows）
- 可选：VS Code + Live Server插件（用于前端可视化）

### 编译步骤
1. 克隆或下载项目到本地
2. 打开项目目录，在地址栏输入 `cmd` 打开命令提示符
3. 执行编译命令：
```bash
gcc main.c user.c ops.c store.c logic.c -o book_system.exe -Wall -fexec-charset=utf-8 -finput-charset=utf-8
```
   - `-Wall`：显示所有警告
   - `-fexec-charset=utf-8`：解决控制台中文乱码
   - `-finput-charset=utf-8`：指定源码编码为UTF-8

### 运行步骤
1. 编译成功后，执行：
```bash
.\book_system.exe
```
2. 程序会自动创建 `data/` 目录
3. 首次运行建议先注册一个管理员账号（角色选1）

## 使用说明
### 1. 注册与登录
- 运行程序 → 选择「2. 注册」→ 输入用户名、密码、角色（1=管理员，2=普通用户）
- 注册成功后选择「1. 登录」→ 输入用户名和密码登录

### 2. 管理员功能
登录管理员账号后可使用：
- 【1】添加图书：输入ISBN、书名、作者、库存数量
- 【2】删除图书：输入ISBN删除（有未归还借阅时无法删除）
- 【3】修改图书库存：输入ISBN和新库存
- 【4】查看图书列表（Live Server预览）：导出数据并打开HTML
- 【5】导出所有数据：手动保存图书和用户数据到CSV
- 【6】重置所有用户每日借阅数：手动清零（一般不需要，自动跨天重置）

### 3. 普通用户功能
登录普通用户账号后可使用：
- 【1】借阅图书：输入ISBN和借阅数量（自动检查跨天重置、库存、每日上限）
- 【2】归还图书：输入ISBN和归还数量
- 【3】查看图书列表（Live Server预览）：导出数据并打开HTML
- 【4】查看今日已借数量：显示今日已借和剩余可借数量

### 4. 前端可视化使用
#### Live Server
1. 用VS Code打开整个项目文件夹（`MyFirstProject`）
2. 安装「Live Server」插件
3. 在C程序中选择「查看图书列表」，或直接在VS Code中右键 `index.html` → 「Open with Live Server」
4. 浏览器自动打开 `http://127.0.0.1:5500/index.html`，自动读取 `data/books.csv`
